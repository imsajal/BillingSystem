
Design and implement a system for an e-commerce app that handles:

Bill creation — given a cart of items (each with price, quantity, category), generate a bill with the total amount.
Discount application — apply one or more discounts to a bill. Support at least these types to start:
Flat discount (e.g., ₹100 off)
Percentage discount (e.g., 10% off)
Category-specific discount (e.g., 20% off electronics only)
The system should be extensible — I should be able to add a new discount type later without rewriting existing code.
